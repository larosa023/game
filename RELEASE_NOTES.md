## What's new
- **Built-in updater**: when a new version is out, the main menu shows an "Update to vX" button. Click it, and the game downloads the update, restarts, and you're on the new version.
- The version number now shows on the main menu.
- Fixed the game crashing on launch and when starting a New Game.
- Saves now live in `%APPDATA%\Oasis\saves`, so updates never touch them.

**How to install:** download **Oasis-windows.zip**, unzip it anywhere, and run `Oasis\Oasis.exe`. Java is included.
